# Taskora

Standalone Next.js landing for Taskora. Dark, sectioned marketing page you can keep building on. The desk app stays in the repo root; this site is only the public face.

```bash
cd "landing page/Taskora"
pnpm dev
```

Open [http://localhost:3001](http://localhost:3001).

| File | What to edit |
|---|---|
| `src/app/page.tsx` | Section order |
| `src/components/*` | Hero, ticker, cards, roles, workflow, markets |
| `src/app/agents/page.tsx` | Agent marketplace stub |
| `src/app/tasks/page.tsx` | Task marketplace stub |
